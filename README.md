# Route & Ritual

Luxury travel proposals should feel like an invitation, not a spreadsheet.

Route & Ritual is a desktop-first proposal workspace for travel advisors. It brings the moving parts of a considered trip into one place, then turns them into a polished, customer-ready proposal that is easy to share.

**Live site:** [route-and-ritual.netlify.app](https://route-and-ritual.netlify.app/)

## What it does

- Builds a journey across destination, dates, stays, transfers, activities, markup, and proposal stages.
- Keeps supplier cost, customer price, margin, and budget headroom visible in a live Trip Ledger.
- Lets advisors shortlist and compare hotels, choose transfers, and shape an unhurried itinerary.
- Produces a share-ready proposal with desktop and mobile views, WhatsApp sharing, and PDF handoff states.

The current journey is a fictional Japan itinerary for Aarav and Meera. Rates and travel data are illustrative, designed to demonstrate the workflow.

## Experience design

The interface is framed by a deep navy workspace, bright editorial surfaces, and champagne-gold action moments. Poppins gives proposal headings a composed, modern voice, while Open Sans keeps detailed planning information clear and readable.

## Run locally

```bash
npm install
npm run dev
```

Then open the local address shown in your terminal.

## Useful commands

| Command | Purpose |
| --- | --- |
| `npm run dev` | Starts the local development experience. |
| `npm run build` | Creates the full application build. |
| `npm run build:netlify` | Creates the static production bundle used for Netlify. |
| `npm run lint` | Checks the codebase for common issues. |

## Deployment

The production site is hosted on Netlify. The project also includes a GitHub Actions workflow that runs the quality checks and Netlify build on pushes and pull requests.
